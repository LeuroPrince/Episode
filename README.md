# PDF Editor

一个运行在本机浏览器中的 PDF 编辑与转换工具。项目使用 Flask 提供本地服务，前端使用原生 HTML/CSS/JavaScript 实现页面预览、拖拽排序、页面旋转、导出路径定位和 PDF 转图片等操作。

## 主要功能

### PDF 编辑

- 导入一个或多个 PDF 文件。
- 导入 PNG、JPG、JPEG、BMP、TIFF、WEBP 等图片文件，并作为 PDF 页面插入。
- 将多个 PDF 和图片合并为一个新的 PDF。
- 每个 PDF 页面都会以缩略图形式显示在预览区。
- 支持拖拽调整页面顺序。
- 支持多选页面后一次拖拽移动，选中的页面会保持原有相对顺序。
- 支持删除单页。
- 支持每页单独左转或右转，旋转后预览区会立即刷新。
- 保存导出时会尽量保留来源 PDF 的书签结构，并将书签页码映射到新的页面顺序。

### 预览区

页面预览区位于主工作区中，用于显示当前项目的所有页面缩略图。

- 上传 PDF 或图片后自动生成页面缩略图。
- 单页旋转后，缩略图会立即按新朝向显示。
- 一键统一页面尺寸后，缩略图会按统一后的页面画布重新渲染。
- 多选页面时，选中的页面卡片会高亮显示。
- 拖拽排序时，页面会根据鼠标所在位置插入到目标页面之间。

### 页面朝向调整

每个页面卡片下方都有独立的朝向按钮：

- `左转`：将当前页面逆时针旋转 90 度。
- `右转`：将当前页面顺时针旋转 90 度。

这些操作只影响对应页面，不会批量修改其他页面。

### 一键统一页面尺寸

`一键统一页面尺寸` 位于 PDF Editor 的页面工具区域。

- 系统会自动选择当前项目中最常见的页面尺寸作为统一画布。
- 保存 PDF 时，所有页面都会被放入该统一画布。
- 页面内容会等比缩放并居中显示。
- 不会裁切页面内容。
- 操作完成后会在提示区显示目标尺寸。
- 预览区会同步更新为统一尺寸后的显示效果。

### 输出路径区

保存 PDF 后，左侧操作区会显示两个入口：

- `下载已保存文件`：通过浏览器下载导出的 PDF。
- `定位到输出 PDF`：调用 Windows 文件资源管理器，并尝试直接选中导出的 PDF 文件。

导出的文件默认保存在：

```text
D:\vibecreature\pdfeditor\workspace\exports
```

### PDF 转图片

PDF 转图片功能位于单独的工具区域。

- 可选择一个 PDF 文件。
- 选择后会在工具内显示 PDF 预览。
- 点击 `转换为 PNG` 后，会把 PDF 每一页导出为 PNG 图片。
- 转换后的图片会保存到 `workspace\exports` 下的独立文件夹中。
- 转换完成后可点击路径按钮打开图片输出文件夹。

### 历史项目

右侧历史项目栏会显示当前服务运行期间创建或编辑过的项目。

- 点击历史项目可恢复到当前工作区。
- 历史项目包含项目名称、页数和最后更新时间。
- 当前实现的历史记录保存在运行内存中，重启服务后会重新开始。

## 启动方式

推荐使用启动脚本：

```text
D:\vibecreature\pdfeditor\launch_pdfeditor.cmd
```

启动脚本会检查本地服务是否已运行。如果服务未运行，会自动启动 Flask 服务并打开浏览器。

也可以手动启动：

```powershell
cd D:\vibecreature\pdfeditor
python app.py
```

然后打开：

```text
http://127.0.0.1:7865
```

## 安装依赖

```powershell
pip install -r requirements.txt
```

## 项目结构

```text
pdfeditor/
  app.py                  Flask 后端服务
  launch_pdfeditor.cmd    Windows 双击启动入口
  launch_pdfeditor.ps1    PowerShell 启动脚本
  requirements.txt        Python 依赖
  templates/
    index.html            主页面模板
  static/
    app.js                前端交互逻辑
    styles.css            页面样式
  workspace/
    uploads/              运行时上传文件
    exports/              运行时导出文件
```

## 注意事项

- 本工具运行在本地 `127.0.0.1`，不会主动上传文件到外部服务器。
- `workspace/uploads` 和 `workspace/exports` 是运行时目录，默认不提交到 Git。
- PDF 压缩、统一页面尺寸和图片转换会生成新文件，不会自动覆盖原始上传文件。
- Windows 资源管理器在某些系统状态下可能复用已打开窗口，但输出路径按钮会使用 `explorer.exe /n,/select` 请求选中具体 PDF 文件。
