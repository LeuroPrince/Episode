打开 Episode

如果无法打开工具，请先双击同一文件夹里的 launch_episode.cmd 启动本地服务，然后再点击“打开 Episode”。

  1. 第一次在新电脑上使用时，先安装 Python，并运行 python -m pip install -r requirements.txt。
  2. 日常使用时，只需要双击 launch_episode.cmd 或打开本页。
  3. 导入和导出的文件只保存在本地 workspace 文件夹，不会自动上传到 GitHub。
